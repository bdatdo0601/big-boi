# Dat's Personal Website Application

Personal Website

## Lambda Functionality

- lambda-layer: Shared code all user
- blog-poller: Pull blog post from Notion
- kinesis consumer: consume from kinesis stream
- url-metadata-resolver: resolve url metadata
- webhook-proxy: proxy webhook from publicly available api to kinesis consumer
- utility-discord-interaction: discord interaction
